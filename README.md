# salat-support

Les deux pages qu'App Store Connect exige pour la fiche de **Salat** : le support et la
politique de confidentialité. Publiées par GitHub Pages sur
<https://sharik-dev.github.io/salat-support/>.

Anglais puis français sur la même page, séparés par un filet — Apple veut une URL par
fiche, pas une par langue, et un lecteur francophone qui atterrit là doit trouver sa
version sans cliquer ailleurs.

La direction artistique est celle de l'app : crème, sable, or, encre brune, titres en
serif, et les blocs portent le contour épais + la face extrudée du langage de formes.
Si la DA de l'app bouge, `style.css` bouge avec.

`privacy.html` décrit deux choses que le code doit continuer de rendre vraies : aucune
requête réseau, et les enregistrements vocaux qui ne quittent pas l'appareil. Les
modifier dans l'app sans les modifier ici transforme cette page en déclaration fausse.
